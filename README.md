# Fintech - Premium Finance Dashboard

Fintech is a high-end, interactive finance dashboard designed to showcase modern frontend capabilities and premium design aesthetics.

## 🚀 Concept & Design Decisions

- **Glassmorphism & Soft Shadows**: Optimized for a high-end, layered feel using Tailwind CSS v4.
- **Dynamic Micro-animations**: Powered by Framer Motion for smooth transitions, card hovers, and data loading effects.
- **Zustand State Management**: Unified state for transactions, filters, and user roles with persistence.
- **3D Depth**: Subtle Three.js background ornaments provide a state-of-the-art visual experience.
- **Indian Locale**: Full support for ₹ (INR) currency formatting and Indian numbering system (Lakhs/Crores).

## ⚙️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 + Custom Design Tokens
- **Component Library**: shadcn/ui
- **Animations**: Framer Motion
- **Charts**: Recharts (Area, Pie, and Bar charts)
- **State**: Zustand with Persist Middleware
- **3D**: @react-three/fiber + @react-three/drei
- **Icons**: Lucide React

## 🧩 Key Features

- **Dashboard Overview**: 
  - Dynamic summary cards (Balance, Income, Expenses).
  - **Wealth Flow**: Time-based balance trend visualization.
  - **Expense DNA**: Categorical spending breakdown.
  - **Recent Activity**: Live feed of latest transactions.
  - **Quick Actions**: One-click access to common tasks.
  - **Monthly Goal**: Visual progress tracking for savings.
- **Transactions Management**: 
  - Advanced filtering by category.
  - Real-time search and multi-column sorting.
  - **Admin Mode**: Add, edit, or delete transactions.
  - **Export**: Download financial data as CSV.
- **Insights & Analytics**:
  - AI-driven savings opportunities.
  - **Monthly Comparison**: Year-to-date income vs. expense bar analysis.
  - Performance highlights (Highest expense, Top category).
- **Profile Section**: 
  - Dedicated profile page for **Suraj Yadav**.
  - Account security and notification settings.
- **Role-Based UI**: Seamlessly toggle between **Viewer** and **Admin** roles to see UI behavior changes.

## 🛠️ Setup Instructions

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. **Open the browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)

_Tip: Use the Profile link in the Topbar or Sidebar to visit Suraj's profile!_
